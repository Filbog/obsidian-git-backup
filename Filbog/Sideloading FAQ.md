### what are extensions and are they necessary
From Reddit:
"app extensions are for all intents and purposes like "helper apps" that need to be installed as well to use some functions, that don‘t have to do with the app directly. uYouTube probably has a "open in youtube" extension, which lets you redirect to youtube videos from Safari, and a notification extension, which allows YouTube to send you notifications. Apps with a widget usually also have a widget extension, even AltStore and SideStore have one.

Are they important for the app to function? No, I haven‘t found an app extension yet that was essential for an app to function. You can usually just remove them and enjoy more app IDs."

So they are **not necessary** for the most part

### What's with the 7-day refresh? 
The 7-day refresh is necessary since 7days is the obligatory period during which we can have an app "unauthorized" officially by Apple (sideloading is an exploit of that), like for development, testing purposes.
We can refresh by:
 - plugging the device to a computer via USB, and using tool like iloader
 - being in the same wi fi network as a computer
 - Using an app like LocalDevVpn that tricks our device thinking it's connected to the same wi fi as a computer. Then we can do it with ANY wi fi network, no need to have our computer in the same wi fi network.

### Can we omit the 7-day refresh?
 - automate it with Shortcuts
 - buy an Apple Developer license or sth, then no refresh.
	 - there are also grey market developer licenses that are much cheaper than Apple's
 - Bunch of other hacky methods like DNS etc
