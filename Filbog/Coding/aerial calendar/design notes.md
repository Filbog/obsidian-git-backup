### basics 
 -  good design is as little design as possible 
	 - essential features, key functionality are focus; 
	 - as little colors as possible
- consistent with spacing, colors, shapes; **use a design system**
	- pick a dark and light color for the text and background, and two colors for the page's personality
	- we need usually two buttons - primary and secondary
- elements need more spacing than we think
- emphasize important stuff OR de-emphasize competing, not as important stuff
- use colors, shadows to create "depth"
- we can use gradient background for "boring" elements
