There are several packages whose aim is to make working with django forms easier - crispy-forms, django-bootstrap5. From my experience, customizing crispy-forms is a nightmare. Lots is happening in python, in crispy-forms weird syntax etc. You also can’t display single form elements with crispy - either whole form or nothing. Which is ridiculous. Forms from django-bootstrap are much more manageable - you can display single elements, so much easier to style and manipulate them with HTML inside the template.
Tl;dr: USE DJANGO-BOOTSTRAP
