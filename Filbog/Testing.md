• Unit tests are small, fast, and isolated to a specific piece of functionality  
• Integration tests are large, slow, and used for testing an entire application or a user flow like payment that covers multiple screens

Developers usually have many unit tests and a few integration tests.
**why to test?** - as our project grows in size - tests make sure we **don't break the code written previously** when introducing new functionality. Easy to diagnose and repair the issue
