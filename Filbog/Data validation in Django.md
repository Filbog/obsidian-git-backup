There are different stages at which we can validate data:
 - model
 - form
 - view
 - front end - template, JS
We can use one or all. Best practice is always model, and then maybe view and/or form. We do it by using "clean" method of the model. Example: aerial-calendar repo, Event model in calendar_app/models.py
