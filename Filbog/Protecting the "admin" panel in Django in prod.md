One of the first things hackers do is to try to access our admin panel. So we don't want to leave the default \<website\>/admin URL. Also, there are cool packages for protecting the admin even more:
 - [django-admin-honeypot](https://github.com/dmpayton/django- admin- honeypot) "will generate a fake admin log in screen and email site admins the IP address of anyone trying to attack your site at /admin. These IP addresses can then be added to a blocked address list for the site."
 - [django-two-factor-auth](https://github.com/Bouke/django- two- factor- auth) will add two-factor authentication to the admin
