### definition #1
A Hypermedia-Driven Application is an application built on top of a hypermedia system that respects and utilizes the hypermedia functionality of that underlying system. So that's different from other client-side systems that utilize JSON APIs (like React, Angular etc)

### definition #2
A web application that uses _hypermedia_ and _hypermedia exchanges_ as its primary mechanism for communicating with a server.
