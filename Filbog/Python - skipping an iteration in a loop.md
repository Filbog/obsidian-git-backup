
we have a ***continue*** keyword for that. If we want to for example skip next iteration in a loop depending on a certain condition in the current iteration, we can set up a ***skip_next*** flag, set it to false and set it to true when we want to skip the next iteration. We also set up an easy if-statement in the loop that if ***skip_next = True***, then we ***continue***

Example is in ***ips_between.py*** kata in https://github.com/Filbog/codewars-katas
