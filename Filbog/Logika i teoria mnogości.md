## Rachunek zdan
### Zdanie w sensie logicznym
**Wyrażenie, o którym mozna stwierdzić, czy jest prawdziwe, czy fałszywe - przypisać wartość logiczną 1 lub 0**
- np zdaniem **nie jest** "Jutro będzie piękna pogoda" - bo jest ono wartościujące, subiektywne - "piękna pogoda" może znaczyć różne pogody dla różnych osób
- zdaniem nie jest x + 2 = 3, 5 - x > 0 - nie wiemy nic o x więc nie jesteśmy w stanie sprawdzić jego wartości logicznej
- inaczej nazwywane **formułą**

### kwantyfikatory
rachunek zdan pozwala mówić o pojedynczych zmiennych; kwantyfikatory pozwalają mówić o **zbiorach**
- ogólny $\forall$ (lub duże /\  ) - "**dla każdego**"
- egzystencjalny, szczegolowy $\exists$ (lub duże \\/ )- "istnieje"

P(x, y) - x jest przyjacielem y
a) Każdy jest przyjacielem każ∂ego - **$\forall$x$\forall$yP(x, y)**
b) Istnieje ktoś, kto jest czyimś przyjacielem - **$\exists$x$\exists$yP(x, y)**
c) Każdy jest czyimś przyjacielem - **$\forall$x$\exists$yP(x, y)**
d) Niektórzy są przyjaciółmi wszystkich **$\exists$x$\forall$yP(x, y)** - (wszyscy mają x za przyjaciela)
e) Wszyscy mają przyjaciół **$\forall$x$\exists$yP(x, y)** (to samo co c)
f) Ktos ma przyjaciela **$\exists$x$\exists$yP(x, y)** (to samo co b)
g) Dla kogoś wszyscy są przyjaciółmi $\exists$x$\forall$yP(x, y)
h) Nikt nie jest przyjacielem wszystkich -( $\exists$x$\forall$yP(x, y) )
i) nikt nie jest niczyim przyjacielem -( **$\exists$x$\exists$yP(x, y)** )

#### zmienna wolna, zmienna związana
- wolna - taka co nie jest przy zadnym kwantyfikatorze
- zwiazana - taka, ktorej nie dotyczy zaden kwantyfikator
- **nawias pokazuje zasięg kwantyfikatorów (scope)**. Czyli np w przykladzie c) w zadaniu 6 - kwantyfikatory "nie sięgają" zmiennych po prawej - więc odp byłaby:
	- "w formule *fi* (po lewej)x, y są związane, z jest zmienną wolną. W formule *psi* (po prawej) x, y i z są zmiennymi wolnymi"
