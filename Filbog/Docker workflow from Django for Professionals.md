#coding #python #djangoforprofessionals 

• create a Dockerfile with custom image instructions • add a .dockerignore file  
• build the image  ***docker build .***
• create a docker-compose.yml file
• spin up the container(s) with ***docker compose up*** (Docker containers can take up a lot of RAM so it's always good to shut them down with Command + C and *docker compose down*)
examples of Dockerfile and docker-compose.yml are on Github: https://github.com/Filbog/django-for-pros-ch4 or any other Django for Pros-related repo
